一、逐条改动前后对比
================================================================
① fitStage 正方形边长（JS 现 L2120-2135）
  前：var side = Math.max(120, Math.min(sw, sh));                 // 取短边
  后：var side = Math.max(120, Math.min(sw, Math.max(120, sh) - 24)); // 边长由屏宽决定，上下各留 12px
  注释：整屏宽 ×（视口高 - 顶栏）；边长由宽度决定，高度不足时兜底。
  → 竖屏：side = 屏宽（占满屏宽）；窄高/横屏：side = 可用高-24（兜底不溢出）。

④ STATE.ring 语义（JS）
  前：STATE = {... ring: 292 };              // 无说明
  后：STATE = {... ring: 292 };  // ring 现为「正方形裁剪边长」
  layout 内：// 图片必须覆盖裁剪圆  →  // 图片必须覆盖裁剪方框

② .xtp-crop-hole 圆形 → 正方形（CSS 现 L952-960）
  前：border-radius: 50%;  box-shadow: 0 0 0 9999px rgba(0,0,0,.62), inset 0 0 0 1px rgba(255,255,255,.9);
  后：box-shadow: 0 0 0 9999px rgba(0, 0, 0, 0.62);   （去圆角 + 去内描边，单边框由 frame 承担）
  注释：// 圆形头像遮罩：圆外 62% 暗色蒙层 + 内描边白圈  →  // 正方形头像遮罩：正方形外 62% 暗色蒙层…

③ 「完成」裁剪逻辑（JS 现 L2308-2322）
  前：ctx.save(); ctx.beginPath(); ctx.arc(out/2,out/2,out/2,0,Math.PI*2); ctx.closePath(); ctx.clip();
      ctx.drawImage(img, sx,sy,sSize,sSize, 0,0,out,out); ctx.restore();
  后：ctx.drawImage(img, sx,sy,sSize,sSize, 0,0,out,out);   // 全幅正方形，不做圆形裁剪
  保留：ctx.fillStyle='#fff'; ctx.fillRect(0,0,out,out);（防透明 PNG 黑边）；out 的 clamp(...,320,1024) 不变。
  → 输出 out×out 正方形 JPEG。

⑤ 全站头像显示 圆形 → 圆角方形（CSS）
  前：.xtp-hero-avatar { border-radius: 50% }                 →  后：border-radius: 12px
  前：.xtp-avatar-row .xtp-avatar-sm { border-radius: 50% }   →  后：border-radius: 12px
  （assets/xt-profile.css 内头像语义处已无 border-radius:50%）
