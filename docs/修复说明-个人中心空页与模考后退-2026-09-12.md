## 一、Bug 1：个人中心「学习偏好」「本机数据」点进去是空白页

### 根因
`个人中心.html` 的 hash 子页路由（`assets/subpage-router.js`）在 `_render()` 中：
1. 先把所有 `[data-subpage]` section 置 `display:'none'`；
2. 再把命中的 section 置 `display:''`（显形）。

但 `prefs` 与 `local-data` 两个 section **内部的 `.card` 被硬编码 `style="display:none"`**：

```html
<section data-subpage="prefs">
  <div class="card" style="display:none" data-page-node-id="sGYAklXD8EhseTlHlPE0D1"> ... </div>
</section>
<section data-subpage="local-data">
  <div class="card" style="display:none" data-page-node-id="dds9xQfNYeivaK5Gv00VeE"> ... </div>
</section>
```

结果：**section 显形了，但内部整张卡片仍是 `display:none` → 用户看到空白页**（标题「个人中心」在，内容区全空）。

### 关键事实：渲染逻辑早已存在，无需补写
`个人中心.html` 底部（原 352–386 行）已定义 `renderProfileOverview()`：
- 填充 `#prefBody`：读 `loadAllSettings()`（每日新增/专注时长/朗读/私信提醒）；
- 填充 `#localStats`：读全局 `appData.stats`（总学习时/做题数/正确率/连续打卡）+ 跳转按钮。

且路由回调（同文件 668–679 行）已在 `key === 'prefs' || key === 'local-data'` 时调用 `renderProfileOverview()`。
**因此本 Bug 唯一成因就是被 `display:none` 遮住**，采用**方案 a**：揭开 `display:none` 即可，**不新造数据源、不伪造数据**。

### 改动（文件 + 行号）
| 文件 | 位置 | 改动 |
|---|---|---|
| `个人中心.html` | L92–96（`section[data-subpage="prefs"]` 内 `.card`） | 删除 `style="display:none"`，并更新注释说明 |
| `个人中心.html` | L105–109（`section[data-subpage="local-data"]` 内 `.card`） | 同上 |

- 保留 DOM 结构（含 `data-page-node-id`）与原「去调整 →」链接（`location.href='设置.html'`）；
- 未删除任何节点、未改类名/ID。

### 验证结果（jsdom 真加载）
- `#prefs` 切换后：section 显示、`.card` `style.display=""`、`#prefBody` 文本=`「📖 每日新增学习内容：50 条…」`（非空、非「加载中…」占位）✅

## 二、Bug 2：模考页后退陷入死循环，退不出页面

### 根因
三个模考页的返回按钮**全部**用 `href="javascript:history.back()"`：
- `mock_exam.html` 原 L131
- `mock_exam_result.html` 原 L202
- `mock_exam_run.html` 原为静态 `href="mock_exam.html"`（无 cat，历史上曾用 `history.back()`）

而页面间用**真链接互相跳转**（exam→run→exam→run…）。
`history.back()` 语义是「回上一步」而非「回上一级」，来回跳几次后历史栈变成 `…→exam→run→exam→run`，
每次返回只在这两页之间乒乓，**永远回不到四级备考/央国企笔试页**。

### 修复方案：改为显式上级页跳转（不再依赖历史栈）
三页各新增一个页面级 `goBack()`（内联脚本，零新文件、不动 APK 白名单），导航语义明确：

| 页面 | 返回目标 | 依据 |
|---|---|---|
| `mock_exam_run.html`（答题页） | `mock_exam.html?cat=<当前卷分类>` | `MockEngine.findPaperCategory(paperId)`：`cet4`→`cet-mock`、`exam`→`exam-mock`；取不到兜底 `cet-mock` |
| `mock_exam.html`（选卷页） | `cet-mock`→`四级备考.html`；`exam-mock`→`央国企笔试.html`；无/未知 cat→兜底 `四级备考.html` | URL 的 `cat` 参数 |
| `mock_exam_result.html`（成绩页） | `mock_exam.html?cat=<本次卷分类>`（**不是** history.back()） | 同答题页，由 `paper` 参数经 `findPaperCategory` 反查 |

- **分类来源**：`assets/mock-engine.js` 的 `findPaperCategory()` 返回 `'cet4'/'exam'`（已存在，未改），映射为 URL 的 `cat`（`cet-mock`/`exam-mock`，与 `data/mock-papers.js` 的 `MOCK_CAT_ALIAS` 一致）——**未猜字段、未写死**。
- **保留原有元素**：三页返回按钮的 `xt-page-back` / `xt-btn` class 与 `data-icon="chevron-left"` 图标 span 原样保留。
- **答题草稿未受影响**：仅改导航目标，未触碰 `beforeunload` 与 `MockEngine` 的草稿持久化逻辑。

### 改动（文件 + 行号）
| 文件 | 位置 | 改动 |
|---|---|---|
| `mock_exam.html` | L131 返回 `<a>` | `href="javascript:history.back()"` → `href="javascript:void(0)" onclick="goBack();return false"` |
| `mock_exam.html` | L381 新增 `function goBack()` | 按 `cat` 跳来源备考页 |
| `mock_exam_run.html` | L479 返回 `<a>` | `href="mock_exam.html"` → `onclick="goBack();return false"` |
| `mock_exam_run.html` | L847 新增 `function goBack()` | 按 `paper`→分类，跳 `mock_exam.html?cat=…` |
| `mock_exam_result.html` | L202 返回 `<a>` | `href="javascript:history.back()"` → `onclick="goBack();return false"` |
| `mock_exam_result.html` | L308 新增 `function goBack()` | 按 `paper`→分类，跳 `mock_exam.html?cat=…` |

> `mock_exam_result.html` 的 error/empty 占位里原有的静态 `<a href="mock_exam.html">返回选卷</a>`（L246/L254）**保持不动**，不影响原功能。

### 验证结果（jsdom 沙箱执行真 `goBack` 源码，捕获导航目标）
- `run(cet-demo-1)` → `mock_exam.html?cat=cet-mock` ✅
- `run(exam-comp-a)` → `mock_exam.html?cat=exam-mock` ✅

- `mock_exam.html` `cat=cet-mock` → `四级备考.html`；`cat=exam-mock` → `央国企笔试.html`；无/未知 cat → `四级备考.html` ✅
- `result(cet-demo-1)` / `result(exam-comp-a)` → 带正确 `cat` 的选卷页 ✅
- 三页均不含真实的 `href="javascript:history.back()"` 返回链接；`goBack` 定义存在；chevron-left 图标保留；div 配平；零未捕获异常；无残留 `?v=20260912c` ✅
