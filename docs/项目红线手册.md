## 1. 账号语义（R142 定型）

- `users.account` = 注册/登录账号（≠随机 ID），默认 = `username`，**原样保留大小写与中文**，`^[一-龥A-Za-z0-9_]{3,20}$`；`_ensure_account` 首选 username，仅空/不合格式/撞名才回退随机 8 位。
- 前端取值三级：`/api/auth/me`.account → 缓存 `xt_profile_account_v2` → 本地登录态 `.account||username`（**禁 toLowerCase/哈希**）→ 游客 derive6。
- 🔴 唯一性与登录匹配一律 `func.lower()`；`username` 注册后不可变但仍可登录（防改号自锁）。
- 🔴 account 可见性 = **仅本人 + 好友**（`users.public_profile` 只在 `target.id==me or 互关` 时下发）；搜索匹配字段须含 `account.like`（改号后仍可被搜到）。
- 30 天一次改号：复用 `profile_change_log`，`CHANGE_FIELDS` 含 `'account'`，标签「账号」；一次性幂等纠偏在 `database.py init_db`。

## 3. Git 推送

- 🔴 `.apk` 不入库 / 不推 GitHub（用户明确）：推前必查 `*.apk` 排除清单。
- 现行主力 = **增量线**（`tools/_r165_push.py`、`tools/_r165_push2.py`，可复制）：本地 commit → `git write-tree` → `git commit-tree <tree> -p <远端main>` → `--force-with-lease=refs/heads/main:<远端main>` 推 `main` → 只发增量对象（实测 7~94 个）。本地历史线（含历史提交）不在祖先链上 → 永不上传。
- 旧「孤儿快照线」（`tools/_r140_push.py`）：`commit-tree` 无父 + 旧 main 先推 `refs/heads/backup/` 零丢失。
- 🔴 推前必做：① socket 探测活代理端口（**用户确认 7897**；env 端口常报 SSL eof）+ 同会话 `ls-remote` 预热 + 立即 push；② **index** 级密钥扫描（`git show :path`；改完工作树先 `git add` 再扫）；③ 收尾核对暂存集（沙箱会随机删文件，必要时恢复误删）。
- 🔴 脱敏标准要含「**片段**」不只「完整 key」（片段表 `tools/_r140_secret_neutralize.py`）；脱敏/扫描脚本**自身不得内嵌密钥片段字面**（用 `_j()` 运行时拼接，否则自己命中自己）；**只能「显式字面表」定向 replace，禁用通用正则**（会误伤守卫字面与检测器正则）。
- 🔴 形态正则打 `sk-` 会命中**已脱敏占位串**（`sk-or-v1-REDACTED-...`，见 `tools/r73m_commit.py`）→ 扫描器须带白名单：命中行含 `REDACTED` 即跳过，否则 `EXIT=5` 误拦截。
- ⚠️ 解析 env 代理串要取**冒号后的端口**（`re.search(r'(\d{2,5})','http://127.0.0.1:7897')` 会先抓到 `127`）。
- 中文 commit 必须 `-F` UTF8 文件；默认只本地提交，用户明确要求才推。禁用 `GIT_SEQUENCE_EDITOR=true git rebase -i`。工作树唯一副本时禁 `reset --hard` / `checkout -- .` / `git gc`。远端核实用 `ls-remote`，别信本地 tracking ref；git 加 `-c core.quotepath=false`。

## 4. 环境坑

- bash **缺 coreutils**（`ls`/`wc`/`head`/`cat`/`grep`/`cp`/`dirname` 全无）；PowerShell stdout 常被吞 → 读/搜用 Glob/Read/Grep，产出用 Write，删文件用 python `os.remove`。别把 `| tail`/`| head` 写进 Bash 命令；长命令重定向到文件再 Read。
- 运行时：python `C:\Users\ATM\.workbuddy\binaries\python\versions\3.13.12\python.exe`；node `C:\Users\ATM\.workbuddy\binaries\node\versions\22.22.2-3\node.exe`。
- jsdom（`NODE_PATH=tools/verifier/node_modules`）是最可靠的前端验证手段；localStorage 垫片必须 `Object.defineProperty`；agent-browser 不可靠。
- 🔴 **jsdom 四坑**：① 注入脚本必须 `w.eval(code)` **直接调用**（用 `.bind(w)` 会跑在 Node 全局域报 `document is undefined`）；② `DOMContentLoaded` 异步派发 → eval 后先 `await sleep(30+)` 再取 DOM，断言「已保存 / 已 PUT」再 `await sleep(40)`；③ 页面残留 timer 会抛 `uncaughtException` 打断测试 → 顶部挂 `process.on('uncaughtException', collect)`，且**不要调 `window.close()`**；④ 页面**内联**脚本里的函数在 jsdom 里**不存在**，要用就在 harness 补 stub，否则误判「功能没生效」。
- 🔴 **断言别把注释 / 文档串一起数**：写「绝不挂 X」「不调 Y」的注释会被自己的断言误判成违规（本机已连踩两次）→ 先剔除注释与 docstring 再判。同理「不得残留旧写法」要锚定**代码形态**（如 `^ *"key" *:`），不能锚定字面词。
- 🔴 TA 视角（`?user=`）的 `boot()` 回调**绝不能调 `renderPage()`**（会把好友资料页覆盖成本人 hero）；入口判断统一 `isOtherMode()`。
- App 专属（老 WebView ≈ Chrome 58：无 `min/max()`、无 `:is/:where`、无 `env()`）问题 jsdom 测不出：用 acorn 语法门槛 + 桥日志取证。Java 编译 `tools/qa/_r10_javac.py`（JDK17 + android-35 + R 桩；基线 10 .java / 86 .class）。
- 🔴 并行改共享大文件前必须重新 Read 最新版；严禁整文件写回（一律 Edit）；终验加防覆盖硬断言。**同一条消息里发多个 Edit（尤其同一文件）会被沙箱静默吞掉一部分** → 改完必须回读或复跑确认。
- 🔴 Python `%`-format：① 拼 shell 模板时 shell 里的 `%` 要写 `%%`（`date +%%Y%%m%%d`）；② **格式化时元组要先解包**（`a, b = f()`，否则 `TypeError: not all arguments converted during string formatting`）；③ `grep` 计数会命中**注释/说明文本**里的字面串 → 锚定形态（如 `^ *"key" *:`）再数。
- 远端中文文件名：**plink 传参 OK**（md5sum/cat 可用），**pscp 会乱码** → 线上中文 HTML 用 `plink cat` 取原始字节比对。
- 测试临时 SQLite 必须**带 pid 唯一命名**（`_rNN_smoke_%d.db`）并硬拦 `data.db`；沙箱 safe-delete 会拦 `os.remove`/`Path.unlink`。
- 🔴 受保护接口的**线上探测口径**：`GET /api/ai/usage` 未登录返回 `models:{}` 空骨架（R88-F 反指纹脱敏）→ **不能用未登录请求探测线上账本明细**；改用免登录的 `POST /api/ai/usage/consume {"modelId":..,"amount":1,"ok":false}`（`ok:false` 只加 failCalls、不动 used）做行为 A/B 对比。

## 5. 前端大坑

- 沉浸式 WebView：任何 fixed 全屏面板 / 私有顶栏必须自接 `var(--xt-satop, env(safe-area-inset-top, 0px))` 垫高（原生把 `--xt-satop` 注入 `documentElement`）。
- 禁 `history.back()` 返回（历史栈乒乓），用显式 `goBack()` 按参数跳上级页（如 `日志.html` 的 `lgBack()` 白名单）。
- 新页必须复制共用 DOM（至少 `#countdownModal`），否则 `app.js` 无守卫 `addEventListener` 抛错打断初始化；子页门控必须 `body:not(.sp-ready) [data-subpage]{display:none}`（裸 `display:none` 压死子页），加 section 必查隐藏空壳。
- 🔴 **可视化页面编辑器污染**：编辑器回写 HTML 时把属性值里的 `>` 误当标签结束符，把 `data-page-node-id` 插进属性值中间劈开属性（R146 真凶 → 源码被当文字渲染）。扫描 `tools/_r146_pageid_scan.py`（A 类污染应恒为 0）。

## 7. AI 通道（R131 零密钥架构）

- 🔴 **provider 级 `apiKey` 必须「整行删除」**，不能只把值换成占位串：`ai-service.js` 的 `xtResolveChannel()` 只要看到 `providers.<平台>.apiKey` 非空，就返回 `relay:false`（强制前端直连、绕过中转）。回归 `tools/_r11g_gemini_channel_check.js`。
- 🔴 **海外平台（gemini/openrouter）就绪判定必须同时看 `relayAvailable`**：`GET /api/ai/models` 对国内平台按「已配 Key」过滤，对海外平台**恒下发**并附 `relayAvailable`（= key 且 proxy 双齐，或显式 `<P>_ALLOW_DIRECT=1`）。只看「平台在列表里」会**假阳性判正常**。回归 `tools/_r11g_relay_available_check.js`。
- 密钥存放口径：内置平台 Key **只在 `server/.env`**（前端零 key）；用户自备 Key 只写 localStorage `ai_user_key_<provider>`（仅 gemini/openrouter 允许 BYOK）；模型级 Key 存 `ai_model_settings.overrides[id].apiKey`（该路径允许前端直连，别误删）。
- 🔴 `server/.env` 的 `GEMINI_API_KEY` 用户明确「以后不要改」→ **只读**（不改 / 不轮换 / 不打码 / 不搬前端）。前端 gemini provider 必须**保持无 `apiKey` 字段**。要可用只有一条路：服务端补 `GEMINI_PROXY`。
- 🔴 **服务器到 Google 系域名直连必被墙**（`generativelanguage.googleapis.com` 等 TCP 超时），`GEMINI_ALLOW_DIRECT=1` 无效；`openrouter.ai`/`www.gstatic.com` 可直连。线上用**服务器本机 mihomo**（`mihomo.service`，`/opt/mihomo/config.yaml`，监听 `127.0.0.1:7897`，仅 Google 系走代理 + `MATCH,DIRECT`），`.env` 配 `GEMINI_PROXY=http://127.0.0.1:7897`。**Gemini 出口地区限制：香港节点 400 `User location is not supported`，只留 us/uk/de/jp。** 见 `docs/服务器Gemini出网代理-mihomo-20260921.md`；机场凭据只存服务器 config(600)，**绝不入库**。

## 9. 实时位置共享（R104e 建 / R144 增强 / R149 修坐标系）

### 服务端 `server/routers/liveloc.py`
- 路由 `/api/live/start|state|tick|stop`。坐标**绝不落库**：tick 只改进程内内存；DB 仅「会话元数据 1 行」+「≥30s 一次的同 ID 心跳 UPDATE」；单进程假定；过期**惰性判定**，不起后台线程；日志绝不打印 lat/lng。常量 `_LIVE_SHARE_MAX_SEC=3600`、`_LIVE_STALE_SEC=60`、`_LIVE_DB_HB_SEC=30`。限流只用 `rate_limit("default")`，**绝不挂 `rate_limit("geo")`**。
- 契约：start 私聊走 `can_message`（好友/管理员）、群聊须成员；`silent:true` 不落卡片（「点进即加入」用）；stop 幂等、仅首次落卡片；tick 仅发起人可调，越权 403（不用 404，避免泄露存在性）。
- 🔴 `/api/live/state` 返回 `{ok,active,count,sessions:[{shareId,sharerId,sharerName,lat,lng,hasFix,acc,updatedAt,stale}]}`（另有顶层旧字段兼容层，优先取 peer 那条）。`hasFix`：lat/lng 均非 None 才就绪，**绝不把 null 转 0**。`acc` 同理：未知 → `null`，**绝不补 0**（0 在前端语义里等于「0 米超准」）。索引 `_LIVE_BY_PEER[(min,max)]` / `_LIVE_BY_GROUP[gid]`；`_hydrate()` 回填时 **acc 无 DB 列 → None**（绝不新增列）。

### 🔴 坐标系铁律（R149 定型）
