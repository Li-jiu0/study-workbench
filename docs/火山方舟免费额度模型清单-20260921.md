## 结论（先看这个）

- **方舟的免费额度是「按模型逐个」给的，不是账号一个总池**：每个模型各送 **50 万 token**（安心体验模式）；未开通也能先用免费额度；**开通服务后仍优先消耗剩余免费额度**；额度耗尽该模型服务自动暂停，不会自动扣费。
- ⇒ 所以判断「我有免费额度的模型」，等价于判断「**哪些模型 API 能调通**」：调不通的模型，额度再多也用不上。
- `/models` 里的 **133 个**模型中，**能调通的只有 42 个** —— 这 42 个就是你有免费额度可用的模型。
- 剩下 **69 个已下线（`Shutdown`）+ 22 个退役中（`Retiring`）**：平台同样给过它们额度，但模型本身已经调不通（实测返回 **404**），额度等于作废。
- ⚠️ 一个必须说清的点：**「能调通」只代表「有额度可用」，不保证额度没用完**。单个模型的免费额度是否已耗尽，方舟的 API 查不到（见下），只能看控制台。

> ⚠️ **免费额度的「余额」查不到 API**：我方舟 key 探了 12 个候选端点（`/usage`、`/quotas`、`/billing/usage`…）全部 404，`/models` 返回字段里也没有额度项。余额只能在控制台看：
> 1. 火山方舟控制台 → **开通管理** → 每个模型那一行的「**免费额度消耗情况**」列；
> 2. 或 **API 密钥管理** → 点你这把 Key 的「详情」→「**用量统计**」（显示「今日已用 / 总免费额度」）。
> 控制台免费额度数据有小时级延迟。

## 额度口径与注意点

- **免费额度按模型独立**：A 模型没用完的额度不能挪给 B 模型用，所以要按模型逐个看。
- **文本 / 对话 / 识图 / 翻译**：每模型 50 万 token（`quotaType: tokens`，项目登记 500000）。
- **图片生成**：按张计，项目登记 200 张/模型（`quotaType: images`）。
- **视频 / 三维**：按任务计，项目登记为 **视频 20 个/模型、三维 60 个/模型**（`quotaType: videos` / `tasks`，R11d 统一补齐）；平台侧的免费额度口径以控制台为准。
- 官方明确：**免费额度只抵扣模型推理消耗的 token，不抵扣插件、知识库等产生的费用**。
- 除免费额度外，方舟还有「**协作奖励计划**」每天 200 万 token（按天重置、不累积），与免费额度是两笔独立的额度。
- 同一模型额度用完后：等额度重置，或在「开通管理」开通付费继续用（开通后仍优先扣免费额度）。
