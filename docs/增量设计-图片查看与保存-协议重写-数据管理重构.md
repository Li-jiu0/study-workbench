## 1.2 可复用查看器 `assets/img-viewer.js`（新文件）

全局单例 `window.ImgViewer`，两套调用方式：

```
ImgViewer.open({ src, name, saveUrl })          // 单图（聊天）
ImgViewer.openList({ urls: [...], index: 0 })   // 多图（朋友圈，左右切换）
```

在 `_IV`（chat-local.js:2395-2470）基础上增强，**保留全部既有交互**，新增：

1. **双指捏合缩放**（ES2017，`touchstart/touchmove` 两指时计算 `dist/dist0` 得 scale，锚点取双指中点；scale 范围 0.5×–4× 与现有一致）；两指并存时禁用单指拖动分支。
2. **加载中 spinner / 失败态**：`img.onload` 前 overlay spinner；`onerror` → 居中「加载失败」+ 重试按钮（重试 = 重新赋 src 加时间戳防缓存）。
3. **保存按钮**（工具条加 ⬇）：调 `xtSaveImage(src)`（见 1.3）；保存中按钮转圈，成功 toast「已保存到相册」，失败 toast 原因。
4. **Android 返回键关闭**：`open()` 时 `history.pushState({xtViewer:1},'')`，`popstate` 事件关闭查看器；同时保留 Esc/背景/✕。关闭时若 stack 顶仍是自己则 `history.back()` 收尾（防栈残留）。约束：pushState 在 `file://` 老内核 WebView 可用性需真机验证，失败则静默降级（不影响其他关闭方式）。
5. 多图模式：左右 `‹ ›` 按钮 + 触摸横向滑动翻页（复用捏合手势判定：单指横滑且 scale≤1 时翻页，否则拖动）。

样式随脚本注入（照 chat-local.js `_IV` 的 boot() 注入范式），类名前缀 `iv-`，不污染全局。

## 1.3 保存：`xtSaveImage(url)`（新，放 img-viewer.js 内）

```
function xtSaveImage(url) {
  // 1) APK 内：window.AndroidBridge.saveImageToGallery 存在 → 原生下载并写相册
  //    返回 'ok' / '__ERROR__:...' / '__UNSUPPORTED__'（同步返回，fetchUrl 同款约定）
  // 2) 纯 Web：fetch(url) → blob → a[download] 触发浏览器下载
}
```

- **原生桥新增**（MainActivity.java 既有 addJavascriptInterface 桥对象内，照 `saveFile:184-198` / `fetchUrl:201-234` 风格）：

```java
@JavascriptInterface
public String saveImageToGallery(final String url, final String filename)
```

  - 子线程语义照 fetchUrl：桥方法内直接 HttpURLConnection 下载（内容类型校验 `image/`，大小上限 20MB）→ 解码为 Bitmap → **Android 10+（API29+）MediaStore.Images** 写 `Pictures/星途`（RELATIVE_PATH，**免存储权限**）；
  - **API<29**：写 `getExternalFilesDir(Environment.DIRECTORY_PICTURES)`（应用专属目录，**零权限**）+ toast 提示保存路径；不做 WRITE_EXTERNAL_STORAGE 运行时申请（minSdk 21，<29 设备占比极低，申请流程复杂度不值；相册不可见是可接受降级，在设计上明示）；
  - 文件名清洗照 saveFile 的 `replaceAll("[\\\\/:*?\"<>|]", "_")`；全程 try/catch，异常返回 `__ERROR__:...`；**日志不打印 URL 参数之外的任何用户内容**。
- **权限申请**：API29+ MediaStore 免权限，无申请流程；如产品后续要求 <29 也写公共相册，再补 `WRITE_EXTERNAL_STORAGE`（Manifest 加 `android:maxSdkVersion="28"`）+ 运行时申请——本期不做。
- **降级链**：桥不存在（纯 Web/旧 APK 缓存）→ a[download]；桥返回 `__UNSUPPORTED__` → 提示「当前版本不支持保存到相册，请升级 App」。
