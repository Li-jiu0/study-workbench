=== A6 _terseGeo 长度约束实测 ===
  用例 短文本
    输出长度 = 21  ≤64 -> true
    实际内容 = "北京市东城区西长安街 天安门城楼 西长安街"
  用例 恰好64
    输出长度 = 64  ≤64 -> true
    实际内容 = "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"
  用例 65超长
    输出长度 = 64  ≤64 -> true
    实际内容 = "BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB…"
  用例 三字段拼接超长
    输出长度 = 64  ≤64 -> true
    实际内容 = "CCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCC DDDDDDDDDDDDDDDDDDDDDD…"
  用例 含空与重复
    输出长度 = 1  ≤64 -> true
    实际内容 = "X"
  用例 全空
    输出长度 = 0  ≤64 -> true
    实际内容 = ""

  边界核算: slice(0,63)+U+2026 的长度 = 64  (U+2026 为单码元 → 64)
  注: 若文本含代理对(emoji/增补平面)，slice 可能截断出半个字符，但 String.length 仍≤64
  含 70 个 emoji 输入 → 输出 String.length = 64  ≤64 -> true
  输出是否含孤立代理项 = true
