# 2026-09-09 安卓 APK 修复 -124 安装失败

## 问题
用户红米 K80（HyperOS 2 / Android 15）安装 v1.0 报「安装失败(-124) 该安装包与您的系统不兼容」。

## 定位
签名方案本身齐全（v1+v2+v3 都通过），targetSdk 33、minSdk 21。搜索确认该 -124 报错原文：
> Failed parse during installPackageLI: Targeting R+ (version 30 and above) requires the resources.arsc of installed APKs to be stored uncompressed and aligned on a 4-byte boundary

用 Python 查 `resources.arsc` compress_type = 8（DEFLATE 压缩）→ 实锤。

## 修复
`android/merge_apk.py` 复制 base.apk 条目时对 `resources.arsc` 强制 `compress_type=zipfile.ZIP_STORED`，交给 `zipalign -f 4`（build-apk.sh 已有）对齐。版本号从 1.0 升到 1.1（versionCode 2）。

## 验证（全绿）
- `resources.arsc` compress_type = 0
- `zipalign -c 4` 权威校验 PASS（资源在 8864，4 对齐）
- apksigner verify PASS
- 19 中文页面 + app.js/common.css/classes.dex 齐全
- MD5 711663fcabfe8e55bc147f3fd73ce436

## 坑点
- 用 Python 算 arsc 数据偏移会误判未对齐（读的是中央目录 extra，没算 zipalign 加进本地头的填充）。**判定对齐一律用 `zipalign -c 4 <apk>`**。
- 重新出包即可，同包名直接全新安装（上次失败未装成功）。
