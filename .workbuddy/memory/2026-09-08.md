### 关键坑（复用价值极高）
1. **aapt2 不认中文路径与中文资产文件名**：工程与 assets 都先复制到 ASCII mktemp 目录；assets 不用 -A，改用 Python zipfile 写入。

# 2026-09-08 学习工作台优化 · 第四轮（修复"更多功能"面板默认露头遮挡）

## 任务
用户截图：左下角"更多功能"标题横条（红框1）一直压在页面内容下方。用户怀疑它遮住了其他内容。

## 根因（隐藏bug）
`.bottom-more-panel#morePanel` 定位为 `position:fixed; bottom:calc(var(--bottom-nav-height)+safe)`，再用 `transform:translateY(100%)` 隐藏。但 `100%` 只下移**面板自身高度**，而它本就 `fixed bottom:64px`，下移后面板顶部仍落在 `视口高度-64px` 处 → **任何页面底部都会漏出约 64px 的"更多功能"标题条**，看起来像遮住了内容。且桌面宽度(1254px)下 `bottom-nav` 为 `display:none`，"更多功能"其实来自这个面板漏出，而非底部导航。

## 修复
- `.bottom-more-panel` 隐藏偏移改为 `transform:translateY(calc(100% + var(--bottom-nav-height) + env(safe-area-inset-bottom,0px)))`，并加 `visibility:hidden`；`.active` 时 `transform:translateY(0); visibility:visible`。
- transition 拆成两条：收起时 transform 0.3s + visibility 延迟 0.3s；展开时仅 transform 0.3s（visibility 立即可见）。

## 验证
- 桌面宽度(1254)：未点开时面板 `top=780(=视口高) visibility=hidden`，完全移出；页面横条消失。
- 点击展开：面板正常上滑，标题"更多功能"+9功能项 + 半透明遮罩正常；等待过渡后收起 `top=780 visibility=hidden active=false` 完全移出。
- div 904:904、`node --check` 通过。
- 截图 `测试截图-更多功能展开.png` 佐证展开态正常。

## 结论/约定
- 平台 fixed 底部定位 + translateY(100%) 隐藏时，若元素带 `bottom` 偏移，必须用 `translateY(calc(100% + 底部偏移))` 才能完全移出视口，否则底部会漏出标题条。
- 该问题为第二轮引入，本轮修复；不影响 AI 面板（其用 display:none 控制）。

### 🔴 `</style>` 标签被吞（最严重 bug，38 分钟才定位）
- 第一处 CSS 插入的 `Edit` 操作 `old_string` 含 `</style>` 但 `new_string` 末尾**没重新写 `</style>`**
- 结果：`<style>=1 / </style>=0`，浏览器 HTML parser 把后续所有内容（body / script 整段）当成 CSS raw-text
- 现象：白屏、`document.scripts.length===0`、`navigateTo===undefined`、`body.children===0`；但 `<title>` 正常（它在 style 之前）
- **修复**：在 `.bc-item .bc-text { ... }` 和 `</head>` 之间 `Edit` 插入 `</style>`；重新校验 `<style`/`</style>` 各为 1 才算完
- **教训**：Edit 替换字符串时若 old_string 含 `</style>`，new_string 必须包含它，否则浏览器会把文档吃掉。**先备份 + 改完 grep 校验开闭标签数量**

### `showBlogView` 内部 bug
初版在第一层 if 里又把 `blogViewList` 强制 `display='block'`，覆盖了第一层 toggle。**改为两行循环**：`Object.keys(map).forEach` 切 5 容器 + 单独循环切 4 tab `.active`

### `editingNoteId` 保存后未清
发布新笔记后 `editingNoteId` 指向新 id，下次"写笔记"tab 继续编辑它而非新开。**抽 `clearEditorFields()`** 重置 `editingNoteId=null` + 全输入 + 预览，`saveBlogNote()` 末尾调一次（新建/更新分支都调）；`resetBlogEditor()` 复用它

### bash 误吞 `$E`
测公式渲染时内容 `面积公式：$E=mc^2$ ...` 用 bash 双引号传入，`$E` 被当未定义变量替换为空 → 公式正则 `/\$([^$]+)\$/` 没法匹配单个尾随 `$`。**改用 `String.fromCharCode(36)` 拼 `$`** 或换单引号/文件传入。代码本身正确

### headless alert 卡死
早期 AI 测试用 `alert('DONE:...')` 弹结果，headless 浏览器挂住导致 10060 超时。**改 `window.__ai = {...}` 赋值 + 单独 eval 读**
