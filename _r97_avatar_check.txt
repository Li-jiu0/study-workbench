一、改了什么（逐条对应 4 项调整）
================================================================
调整1 · 移除底部缩放进度条
  JS：
    - 删除常量 CROP_ZOOM_SVG（原 L2089-2090）。
    - openCropper DOM 模板里删除整个 <div class="xtp-crop-bottom" id="xtpCropBottom">…</div>（含放大镜图标 + #xtpCropZoom range）。
    - 删除 DOM 引用 var zoom = .../var bottom = ...；ZMIN/ZMAX 注释更新（不再提滑杆）。
    - fitStage()：删除 botH，可用高 = 视口高 - 顶栏（sh = vh - topH）。
    - zoomAt()：删除 `if (zoom) { zoom.value = ... }` 滑杆同步行。
    - 删除滑杆 input 监听（原 L2305-2306）。
  CSS：
    - 删除 .xtp-crop-bottom / .xtp-crop-zi / .xtp-crop-zoom 及 ::-webkit-slider-runnable-track / ::-webkit-slider-thumb / ::-moz-range-track / ::-moz-range-thumb 全部规则。
  → 双指捏合 + 拖动 + 桌面滚轮缩放全部保留并且已真跑验证（见四）。

调整2 · 裁剪框加 3×3 淡灰九宫格
  CSS（纯 CSS，无额外 DOM/JS）：.xtp-crop-frame 增加 background-image，4 条 linear-gradient：
    2 条竖线（to right，33.333% / 66.666%）+ 2 条横线（to bottom，33.333% / 66.666%），
    线宽 1px（calc ±0.5px），颜色 rgba(255,255,255,0.28)（暗底上的淡灰观感，未用纯白）。
  层级：frame 在 hole 之下（DOM 顺序 frame → hole），九宫格超出圆的部分被 hole 的 62% 暗色蒙层 box-shadow 自然盖住，符合微信观感。
  未引入 clamp()/min()/max()（本项目禁用），仅用 calc()。

调整3 · 顶部只留「取消」「完成」
  CSS：删除 .xtp-crop-topbar::after 整块（即「拖动 / 双指缩放调整头像」提示，原 L925-941）。
  保留 .xtp-crop-topbar 的 justify-content: space-between → 两按钮分居左右，中间留空（未改居中）。
  完成按钮仍为微信绿 #07c160（.xtp-crop-btn.primary 未动）。
  JS：同步更新块注释，去掉「底部缩放滑杆」等已删设计描述（不写冗余版本信息、不含带版本号的资源路径）。

调整4 · 点「编辑头像」先弹底部选择弹窗（新增 ActionSheet）
  JS 新增：
    xtpOpenAvatarSheet()：自建遮罩 .xtp-mask.xtp-sheet-mask，id="xtpMask"（复用统一关闭口 closeModal/xtpCloseModal）；
      面板 .xtp-sheet 含「拍照」(#xtpSheetCamera) /「从手机相册选择」(#xtpSheetAlbum) 两项 + 独立分隔的「取消」(#xtpSheetCancel)；
      点遮罩空白（target===mask）关闭，与微信一致。
    xtpPickAvatarFile(useCamera)：关闭面板 → 创建隐藏 file input（accept=image/*）；
      useCamera=true 加 capture="environment" 调起相机（桌面浏览器忽略 capture 退化为普通选图，注释已写明）；
      useCamera=false 不带 capture；change 后复用原有 FileReader → openCropper(url) 链路，未重写。
    xtpPickAvatar()：改为只调用 xtpOpenAvatarSheet()（不再直接进相册）。
  CSS 新增：.xtp-sheet-mask / @keyframes xtpSheetMaskIn / .xtp-sheet / @keyframes xtpSheetIn /
    .xtp-sheet-list / .xtp-sheet-item / .xtp-sheet-cancel / .xtp-sheet-gap；
    白底（var(--xtp-card)）圆角顶部、三项纵向、取消与上两项间 8px 灰隙独立成块、padding-bottom: env(safe-area-inset-bottom)。
  未使用 prompt/alert/confirm（遵守产品硬约束）；仅 ES2017（var/function）。

未改动（严格遵守纪律）：
  - 「完成」按钮的 canvas 裁剪 + saveProfile({avatarImg}) + renderPage + toast 逻辑（原 L2314-2346）一字未动。
  - 圆形遮罩 .xtp-crop-hole 保留。
  - 版本戳等其它文件未触碰。
