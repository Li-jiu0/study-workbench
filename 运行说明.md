## 二、启动步骤

### 1. 启动后端（必须先启动）



```
cd server

pip install -r requirements.txt      # 首次

copy .env.example .env              # Windows（Linux/Mac 用 cp）

\#   编辑 .env：至少改 JWT\_SECRET；要启用 AI 就填对应 API Key

python -m uvicorn main:app --host 0.0.0.0 --port 8000
```



* 首次启动自动创建 `server/data.db`（SQLite，表结构见 `server/建表SQL.sql`）。

* 验证：浏览器打开 [http://localhost:8000/api/health](http://localhost:8000/api/health)，返回 `{"ok":true,...}` 即成功。

### 2. 打开前端

直接双击 `学习工作台.html`（file:// 协议）即可，`assets/api.js` 会自动请求

`http://localhost:8000`；也可以用任意静态服务器托管整个目录（此时用同源相对地址）。

未登录访问任何页面都会被强制跳到 `登录.html`；在登录页切换「注 册」即可让新访客注册账号。

### 3. AI 功能（安全模式）



1. 在 `server/.env` 里给需要的模型填 Key（DeepSeek / 通义 / Kimi / 智谱 / OpenAI 任选），重启后端；

2. 前端「设置 → AI 模型选择」只有**模型下拉框**，没有任何密钥输入框；

3. 右下角 AI 助手与「写笔记 → AI 辅助」都通过后端 `/api/ai/chat` 流式中转。

   前端全链路接触不到密钥；`.env` 请勿提交到代码仓库。

## 三、建表 SQL（server / 建表 SQL.sql 同步收录）

后端用 SQLAlchemy 自动建表，人工核对或手工初始化可用：



```
PRAGMA foreign\_keys = ON;

CREATE TABLE users (

&#x20; id            INTEGER PRIMARY KEY AUTOINCREMENT,

&#x20; username      TEXT    NOT NULL UNIQUE,     -- 登录账号

&#x20; password\_hash TEXT    NOT NULL,            -- PBKDF2-SHA256（盐 + 12万轮）

&#x20; nickname      TEXT    NOT NULL,

&#x20; motto         TEXT    NOT NULL DEFAULT '',

&#x20; avatar        TEXT,                       -- 头像URL（文件存 uploads/avatars/）

&#x20; created\_at    TEXT    NOT NULL

);

CREATE TABLE notes (

&#x20; id            INTEGER PRIMARY KEY AUTOINCREMENT,

&#x20; user\_id       INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,

&#x20; title         TEXT    NOT NULL,

&#x20; category      TEXT    NOT NULL DEFAULT 'other',

&#x20; privacy       TEXT    NOT NULL DEFAULT 'public'  CHECK (privacy IN ('public','private')),

&#x20; status        TEXT    NOT NULL DEFAULT 'draft'  CHECK (status IN ('published','draft','archived')),

&#x20; cover         TEXT,

&#x20; tags          TEXT    NOT NULL DEFAULT '\[]',   -- JSON数组

&#x20; content       TEXT    NOT NULL DEFAULT '',      -- Markdown 正文

&#x20; excerpt       TEXT    NOT NULL DEFAULT '',

&#x20; views         INTEGER NOT NULL DEFAULT 0,

&#x20; likes\_count   INTEGER NOT NULL DEFAULT 0,

&#x20; comments\_count INTEGER NOT NULL DEFAULT 0,

&#x20; created\_at    TEXT    NOT NULL,

&#x20; updated\_at    TEXT    NOT NULL

);

CREATE TABLE likes (      -- UNIQUE(note\_id,user\_id)

&#x20; id INTEGER PRIMARY KEY AUTOINCREMENT,

&#x20; note\_id INTEGER NOT NULL REFERENCES notes(id) ON DELETE CASCADE,

&#x20; user\_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,

&#x20; created\_at TEXT NOT NULL

);

CREATE TABLE favorites (  -- UNIQUE(note\_id,user\_id)

&#x20; id INTEGER PRIMARY KEY AUTOINCREMENT,

&#x20; note\_id INTEGER NOT NULL REFERENCES notes(id) ON DELETE CASCADE,

&#x20; user\_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,

&#x20; created\_at TEXT NOT NULL

);

CREATE TABLE comments (

&#x20; id INTEGER PRIMARY KEY AUTOINCREMENT,

&#x20; note\_id INTEGER NOT NULL REFERENCES notes(id) ON DELETE CASCADE,

&#x20; user\_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,

&#x20; content  TEXT NOT NULL,

&#x20; created\_at TEXT NOT NULL

);

CREATE TABLE notifications (  -- 点赞/评论提醒（通知笔记作者）

&#x20; id INTEGER PRIMARY KEY AUTOINCREMENT,

&#x20; user\_id  INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,  -- 收信人

&#x20; actor\_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,  -- 触发人

&#x20; type     TEXT    NOT NULL CHECK (type IN ('like','comment')),

&#x20; note\_id  INTEGER REFERENCES notes(id) ON DELETE CASCADE,

&#x20; is\_read  INTEGER NOT NULL DEFAULT 0,

&#x20; created\_at TEXT NOT NULL

);
```

## 四、旧本地笔记如何迁移到服务器

**方式一（推荐）：页面一键迁移**



1. 启动后端并用**旧账号对应的浏览器**打开任意页面并登录；

2. 进入「设置 → 📥 本地笔记迁移」点击「一键迁移」；

3. 该浏览器 localStorage 里 `study_workbench_data` 的全部笔记（含标签、点赞数、评论、草稿 / 归档状态、私密属性）会 POST 到 `/api/migrate/notes`，写入当前登录用户名下；

4. 迁移按「标题 + 创建时间」去重，**重复点击不会产生重复笔记**；换浏览器 / 换电脑后需要重新执行一次。

**方式二：手工调用接口**



```
\# 1) 登录拿 token

curl -X POST http://localhost:8000/api/auth/login \\

&#x20; -H "Content-Type: application/json" \\

&#x20; -d '{"username":"你的账号","password":"你的密码"}'

\# 返回 {"token":"eyJhbGci...","user":{...}}

\# 2) 把 localStorage 里 study\_workbench\_data.notes 数组存成 notes.json，然后：

curl -X POST http://localhost:8000/api/migrate/notes \\

&#x20; -H "Authorization: Bearer 上一步的token" \\

&#x20; -H "Content-Type: application/json" \\

&#x20; -d @notes.json   # 内容形如 {"notes":\[ {...旧笔记对象...}, ... ]}
```

迁移字段映射：旧 `id`（n\_xxx）不保留，服务器分配数字 ID；旧评论（单用户时代的自评）会归到当前用户名下；旧 `views/likes` 计数原样带入。

## 七、常见问题



* **页面一直跳登录页**：先确认后端已启动（/api/health 可访问）；若已登录仍跳转，清掉 localStorage 里的 `study_workbench_token` 与 `study_workbench_auth` 重新登录。

* **头像 / 插图不显示**：`server/uploads/` 目录由后端静态挂载在 `/uploads`，file:// 打开时前端会自动拼 `http://localhost:8000` 前缀。

* **AI 报「未配置密钥」**：`server/.env` 对应 `*_API_KEY` 未填或填后未重启 uvicorn。

* **旧的 Express 版 ai-server/**：已被 FastAPI 后端取代，可整体删除，不影响任何功能。
