# OCR 噪声清洗 — 高置信替换表分析报告

- 生成日期：2026-09-15
- 数据源：`assets/app.js` 中 5 个行测题库数组（`q` 题干 + `o` 选项）


## ① 方法

1. **语料自建**：从 app.js 单行数组中解析出 4488 条题目，拼接 `q`+`o` 为 546,447 个汉字的语料，
   建立字符 / 二字组 / 三字组频次表（3,675 个不同汉字、119,308 个二字组、244,554 个三字组）。
2. **低频字检测**（第 1 轮）：抽查频次 ≤ 8 的 1,233 个汉字。**结论：不可用**——
   行测常识/言语题本身含大量合法生僻字（冰淇淋、鄱阳湖、华佗、砗磲、狒狒…），
   低频信号被完全淹没，此路放弃。
3. **字形先验 + 语料验证**（第 2 轮，主方法）：人工整理 636 个汉字的 OCR 形近/混淆组
   （`_work/confuse.py`，共 3,072 个混淆对），对语料中每个混淆字检查其左右邻接二字组的支持度：
   若「当前字」的邻接二字组支持度极低（≤2），而组内某个形近字的同样位置支持度极高（≥8 且 ≥5 倍），
   则列为候选。再由人工逐条核对上下文裁定。
4. **词级变体对照**（第 3 轮）：对每个混淆对 (a,b)，扫描所有「a 参与的低频二字组」，
   若换成 b 后该二字组在语料中出现 ≥25 次且 ≥8 倍，则生成候选规则。
5. **碰撞检测（决定性一步）**：每条候选规则都回到全量语料做左右邻碰撞检查。
   凡存在任何一种「合法词被切断」的情形（如 `年未` 与 `百年未有`、`列人` 与 `下列人员`、
   `加人` 与 `参加人/增加人`）**一律放弃**，或改写成更长的无歧义片段。
6. **证据门槛**：规则须满足 ≥2 处独立出现，或仅 1 处但上下文中可 100% 断定
   （如 `调亡` 所在题同一段另有 `凋亡小体`；`分辨瓣率` 所在题前文已有 `分辨率`）。

### 5.3 OCR 漏字 / 乱码类（非字符串替换可安全修复）

| 现象 | 示例 | 放弃原因 |
|---|---|---|
| 漏字 | `人论世` 应为 `知人论世`（id1263） | 需插入字符，且插入位置依赖语义，无法保证不误插 |
| 漏字 | `跌\n起伏` 应为 `跌宕起伏`（id2231） | 同上 |
| 漏字 | `抓是对皮肤瘙痒感觉的一种反应`（id3805）应为 `抓挠` | 同上 |
| 漏字 | `传感器\n各类静态地物后`（id1611）应为 `识别出各类静态地物后` | 同上 |
| 乱码 | `弓[发` / `弓「发` 应为 `引发`（id3718、id1888） | 垃圾符号形态不稳定，建议后续用正则 `弓\[?`?发` → `引发` 单独处理 |
| 数字范围符 | `2021年1一2月`（id4278、id4385）中 `一` 实为连接号 | 属数字/符号域，按约定不改动 |
| 单字扩写 | `碟进化出了…`（id1029 o0）应为 `砗磲进化出了…` | 1 字 → 2 字替换，规则表只做等长安全替换 |
| 存疑地名 | `西川`（id2085 o3）疑为 `四川` | 「西川」亦是历史地名（剑南西川），无法排除 |

### 5.4 方法层面的放弃
- **通用简繁转换**：不做（按要求）。
- **英文/数字/公式**：不做（`300300`、`x（x-1）=30` 等为分数排版被拆行，属已知正常现象）。
- **`[IMG:...]` 引用、题型名/子题型名**：全程未纳入清洗范围。
