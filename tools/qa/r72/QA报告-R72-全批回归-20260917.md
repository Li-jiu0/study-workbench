以下为受环境/范围约束未做端到端动态验证的项，均非功能缺陷，且已在源码层或静态层确认：

2. **后端在线好友 presence / WebSocket 推送**：`store_and_deliver` 的 `await send_to`、轮询在线状态为运行时行为，仅后端契约层验证（依赖 override `wsmanager.send_to=_noop_send`）；真实 WebSocket 推送未做跨进程联调。
3. **AI 真实模型调用（在线模式）**：`ai-service.js` 仅验证守卫/降级/并发逻辑与字段，未对真实第三方 API 发请求（不涉及密钥、不产生产生费用）。
4. **登录页真实跳转链路**：`location.replace` 在 jsdom 中被桩替换为空函数，仅验证文案/模式探测分支逻辑，未真跳转。
5. **完整浏览器视觉布局（需求13）**：jsdom 无真实排版引擎，布局验证为源码级近似（媒体查询 + flex-basis 字节），未做像素级视觉核对。
