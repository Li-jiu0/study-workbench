三、server/routers/ai.py 改动明细
--------------------------------------------------------------------------------
P1  在 GET /history（现 L181-196）之后、POST /chat 之前新增：
    @router.delete("/history") def ai_history_delete(ids: str="", user, db)
    - 鉴权与存储：与 GET /history 完全同套 —— get_current_user + SQLAlchemy AiLog，
      按 user_id 过滤，只能删本人记录；
    - 不带 ids → 清空本人全部记录；ids=1,2,3（可选）→ 仅删指定主键 id 的本人记录，
      他人 id 静默忽略；非法 id 返回 400；
    - 返回 {"ok": True, "deleted": 删除条数}；q.delete(synchronize_session=False)+commit；
    - 未改 GET /history 与 POST /chat 任何行为；
    - 设计假设：ai_logs 是扁平消息表（无 session_id 列），故 DELETE 不支持 session_id
      维度（任务清单中的「session_id 或 ids」取 ids 实现），假设已在上游 docstring 注明；
      AiUsage 每日计数与模型用量账本不受影响。
