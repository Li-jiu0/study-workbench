【R144 · 实时位置共享增强（仅 live-location.html）】
- 触发条件：本次 /api/live/state 返回的会话中「有效位置点」（hasFix===true 且 lat/lng 有限）
  ≥2 时才绘制连线与距离标注；<2 清空连线层并收起导航按钮（单方共享体验不变）。
- 多点连接方式：2 点一条直线段；≥3 点按稳定顺序连成闭合环。稳定顺序 = 自己排首位，
  其余按 sharerId 字符串升序 → 轮询返回顺序抖动不会让线条跳变。
- 距离计算规则：复用既有 haversineM（球面大圆距离，R=6371000m）即两点间直线距离；
  每段标注在该段中点；≥3 点另在几何中心（各点经纬度算术平均）标注
  「N 人 · 最远 X · 最近 Y」（两两全组合取极值）。文案：<1km 用「米」，≥1km 用「公里」
  （<10km 一位小数，≥10km 取整）。
- 更新时机：每次 /api/live/state 轮询（POLL_MS=4000ms）后经 onState → renderLinks 重算重绘；
  用「点位签名」（每点 sharerId + 坐标 5 位小数）比对，签名未变则跳过重绘（防闪烁、省开销），
  任一参与方坐标变化则整层替换、距离数值同步刷新；共享结束经 clearAllMarkers → clearLinks 清理。
- 导航跳转行为：有效点 ≥2 时右下角「导航」按钮 → bottom sheet；起点默认「我的位置」
  （自己没有有效坐标时取排序后首个他人点，可在胶囊行切换），终点为其余参与方并显示与起点的
  直线距离；点「导航」拼高德 H5 URI（uri.amap.com/navigation，coordinate=gaode、callnative=1）
  经 location.href 唤起（装了高德直接进 App，否则打开其网页版），异常回退 window.open；
  行内「复制」把 lat,lng 写入剪贴板（clipboard API → execCommand 兜底）。
  坐标按 GCJ-02 口径解释（与腾讯矢量瓦片、高德一致），不做 BD-09 转换。
- 三件套：新增 #llNav / #llSheet / #llOriginRow / #llRows 容器 + .ll-dlabel / .ll-nav / .ll-sheet
  等样式 + 独立函数块；原有 DOM 与功能全部保留。文件末尾新增 window.__LL_TEST__ 测试句柄
  （沿用 chat-local.js 的 __IM_TEST__ 惯例）。
