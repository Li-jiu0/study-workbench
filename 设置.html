帮助与反馈
消息发不出去怎么办？▾
① 确认后端已启动（设置页右上角能收到通知说明在线）；② 只能与好友互发消息，先在「好友」页添加；③ 若被对方拉黑会提示「无法发送消息」。离线时聊天会自动切到本地演示模式。
图片 / 头像不显示？▾
图片由后端 uploads 目录提供。file:// 打开页面时会自动拼接后端地址；请确认后端在运行，且没有浏览器插件拦截图片。
密码忘记了怎么找回？▾
当前版本暂不支持自助找回，请联系管理员在服务器端重置。注册后建议在「账号与安全」里记好密码。
换电脑 / 换浏览器数据还在吗？▾
发贴、好友、消息存在服务器，登录即恢复；词汇进度、错题本等学习数据保存在本机，可在「数据管理」导出 JSON 备份后导入新设备。
AI 功能报「未配置密钥」？▾
密钥由管理员配置在服务器端，前端不接触任何密钥。若提示未配置，请联系管理员在 server/.env 填写对应 API Key 并重启后端。
反馈提交了没人回？▾
反馈会进入开发者的处理队列，状态会显示在下方「我的反馈」里（待处理 / 已回复）。提交成功会返回一个编号（如 #123），方便追踪。
